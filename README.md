# galvinlam.github.io

Source for my portfolio site, **[galvinlam.github.io](https://galvinlam.github.io)**: one static page, no build step, hosted on GitHub Pages.

| [ai-research-brief-builder](https://github.com/galvinlam/ai-research-brief-builder) | A research assistant that shows its evidence, confidence and disagreements |
| [bot-battle](https://github.com/galvinlam/bot-battle) | A browser game where the enemies make their own decisions |
| [agent-playground](https://github.com/galvinlam/agent-playground) | A simulation that makes agent decisions visible |
| [meme-sniper](https://github.com/galvinlam/meme-sniper) | A real-time screening engine for new Solana token launches |
